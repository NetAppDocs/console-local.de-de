* Beim Bereitstellen eines neuen Agenten testet die Validierungsprüfung die Verbindung zu den aktuellen Endpunkten. Wenn link:reference-networking-saas-console-previous.html["vorherige Endpunkte"] verwendet wird, schlägt die Validierungsprüfung fehl. Um diesen Fehler zu vermeiden, sollte die Validierungsprüfung übersprungen werden.
+
Obwohl die bisherigen Endpunkte weiterhin unterstützt werden, empfiehlt NetApp, Ihre Firewall-Regeln so bald wie möglich auf die aktuellen Endpunkte zu aktualisieren. link:reference-networking-saas-console-previous.html#update-endpoint-list["Informationen zum Aktualisieren Ihrer Endpunktliste"].

* Wenn die Firewall auf die aktuellen Endpunkte aktualisiert wird, funktionieren die bestehenden Agenten weiterhin.


^1^ NetApp empfiehlt, Endpunkte der Option 1 in Ihrer Firewall zuzulassen, da diese sicherer sind, und Endpunkte der Option 2 zu unterbinden. Zu diesen Endpunkten ist Folgendes zu beachten:

+ * Ab der Version 3.9.47 des Console Agent unterstützt das System die in Option 1 aufgeführten Endpunkte. Frühere Versionen des Console Agent unterstützen keine Abwärtskompatibilität. * Der Console Agent kontaktiert zuerst die Endpunkte in Option 2. Sind diese Endpunkte nicht erreichbar, werden automatisch die Endpunkte in Option 1 kontaktiert. * Bei Verwendung des Console Agent mit NetApp Backup and Recovery oder Ransomware Resilience unterstützt das System die Endpunkte von Option 1 nicht. Option 2 Endpunkte sind zuzulassen und Option 1 Endpunkte nicht zuzulassen.
